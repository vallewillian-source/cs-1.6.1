# Compatibility CLI

The implementation moved into the independent `mods/bots-jev/` package.
`run.sh --report` reports decisions and API-reported token usage from the current
state directory. `scripts/run-botbrain.sh` starts a managed local server and its
sidecars. Use `scripts/run-cs.sh` to include the flat client.

See `docs/BOTBRAIN.md` and `docs/MODS.md` for credentials, protocol and controls.
