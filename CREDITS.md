# Credits and licenses

CS 1.6.1 mixes original code with third-party content. This file lists what comes from
outside and under which license, so provenance stays traceable.

## Project license

The code and documentation written for this project are **GPL-3.0** — see [LICENSE](LICENSE).
That is the conservative choice, not an accident:

- the VR Mod is compiled against the engine's Mod ABI header (`engine/common/mod_api.h`),
  which belongs to Xash3D-FWGS (GPL-3.0), and `patches/xash3d-fwgs-mod-abi/` is a diff
  against that same GPL-3.0 tree;
- every component listed below is GPL-3.0 compatible.

Third-party components keep their own licenses. The README inside each patch directory
repeats the upstream license of the code it modifies.

## What is *not* in this repository

Counter-Strike's game content (maps, models, sprites, sounds) is Valve's property. **None of
it is distributed here.** `.gitignore` keeps the content directories out of version control,
and the build steps download it from Valve's own CDN through SteamCMD with an anonymous
login — see [docs/BUILD.md](docs/BUILD.md). The engine, client and game DLL binaries are not
vendored either: the build scripts clone and compile them from source.

Three tracked files deserve a note, because all of them are *derived* data rather than Valve
content:

- `server/cstrike/maps/de_dust2.nav` — the bot navigation graph for `de_dust2`, generated by
  the bot system from the map. It is required for the bots to move at all, and contains only
  navigation nodes, not map geometry.
- `server/cstrike/BotProfile.db` and `BotChatter.db` — bot personality and radio-chatter
  tables written for this project.

## Bitmap font in the VR debug panel and HUD

The Mod cannot link FreeType — it may not link against anything outside the engine — so the
font is a bitmap atlas generated by [`mods/vr/gen_font.py`](mods/vr/gen_font.py) from the
system console font (`kbd` PSF, 8×16, VGA-like, public domain), covering printable ASCII
(32–126). `mods/vr/vr_font.h` is **generated — do not hand-edit**;
`mods/vr/vr_font_preview.png` is its preview image.
